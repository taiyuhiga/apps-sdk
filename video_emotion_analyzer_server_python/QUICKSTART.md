YouTube動画の感情分析を3ステップで行うMCPサーバーのクイックスタートガイドです。

## 🚀 クイックスタート（5分で開始）

### 1. サーバーの起動

```bash

export YOUTUBE_API_KEY="AIzaSyDp1LoSRBU8-xMoPDqbYNjG6p4NfID5VXs"
venv/bin/uvicorn main:app --host 0.0.0.0 --port 8004

https://www.youtube.com/watch?v=VIDEO_ID
```

## 📋 分析の流れ

サーバーは3つのステップで自動的に分析を進めます：

### ステップ1: シナリオ分析 🎬

**ツール**: `analyze-scenario`

- 動画の文字起こしを自動取得（youtube-transcript-api使用）
- 視聴者の感情を引き出す要素を分析
- 9つの質問に基づいて詳細に分析

**分析内容**:
1. 感情が動かされる場面
2. 自分事化できるポイント
3. 感情を動かす台本箇所
4. ターゲット層の特定
5. 価値観との結びつき
6. 視聴後の感情
7. 社会的関心事との結びつき
8. 次に観たい企画
9. 学びの内容

→ **分析完了後、AIが自動的にステップ2へ進みます**

### ステップ2: コメント分析 💬

**ツール**: `analyze-comments`

- YouTube Data APIでコメントを取得（最大1000件）
- いいね数順にソートして分析
- 実際の視聴者の反応を詳細に分析

**分析内容**:
1. 実際に感情が動かされた場面
2. 最も多かったコメント内容
3. 盛り上がった部分
4. 年齢層と男女比の推測
5. 個人的経験との結びつき
6. 発信者への共感ポイント
7. 社会的話題との関連
8. 典型的な感情（喜び、悲しみ、驚き等）
9. 学びや教訓

→ **分析完了後、AIが自動的にステップ3へ進みます**

### ステップ3: 感情分析 ❤️

**ツール**: `analyze-emotion`

- ステップ1とステップ2の結果を統合
- 視聴者の感情を深く理解
- コンテンツ改善の具体的な提案

**分析内容**:

#### 1. 具体的（行動指向）な目的
- 賛同を得ている具体的要素の特定
- 視聴者が求める共通トピック
- チャンネル固有の強みと強化方法

#### 2. 視聴者理解（コンセプト指向）の目的
- 心理的欲求の分析
- 共有・拡散のトリガー
- 同質性と多様性のバランス

→ **全ての分析が完了！**

## 🔧 トラブルシューティング

### サーバーが起動しない

```bash
# ログを確認
tail -f video_emotion_analyzer_server_python/server.log

# ポートが使用中の場合
lsof -ti:8004 | xargs kill -9
```

### YouTube API エラー

**エラー**: "YOUTUBE_API_KEY環境変数が設定されていません"

**解決策**:
```bash
export YOUTUBE_API_KEY="AIzaSyDp1LoSRBU8-xMoPDqbYNjG6p4NfID5VXs"
```

**エラー**: "APIの使用制限に達しました"

**解決策**: 
- YouTube Data API v3の無料枠: 1日10,000クォータ
- コメント取得: 1リクエスト = 1クォータ
- 翌日まで待つか、別のAPIキーを使用

### 文字起こしが取得できない

**原因**:
- 動画に字幕が有効になっていない
- 自動生成字幕がオフになっている

**解決策**:
- 字幕が有効な動画を選択
- 手動で作成された字幕がある動画を優先

### コメントが取得できない

**原因**:
- 動画のコメントが無効
- プライベート動画

**解決策**:
- コメントが有効な公開動画を選択

## 💡 Tips

### 1. 効果的な分析のために

- **人気動画を選ぶ**: コメント数が多い動画ほど詳細な分析が可能
- **字幕付き動画**: 手動で作成された字幕がある動画が最適
- **最新動画**: 最近の社会的関心事と結びつけやすい

### 2. 分析結果の活用

- **コンテンツ改善**: 視聴者が求める要素を特定
- **企画立案**: 次に作るべき動画のヒント
- **ターゲット理解**: より深い視聴者理解

### 3. 複数動画の比較

複数の動画を順番に分析して比較することで：
- 成功パターンの発見
- 視聴者の好みの変化
- チャンネルの強み・弱みの特定
