# YouTube動画感情分析サーバー - 使い方

## 🎯 概要

このMCPサーバーは、YouTube動画を3ステップで感情分析します：

1. **シナリオ分析** 📝 - 動画の文字起こしから視聴者の感情を予測
2. **コメント分析** 💬 - 実際のコメントから視聴者の反応を分析
3. **感情分析** ❤️ - 2つの結果を統合して深い洞察を得る

```bash
cd video_emotion_analyzer_server_python

venv/bin/uvicorn main:app --host 0.0.0.0 --port 8004
```

### 2. ngrokで公開（新しいターミナルで）

```bash
ngrok http 8004
```

### 3. MCP URLをコピー

ngrokの出力から以下の形式のURLを見つけてコピー：

```
https://xxxx-xxx-xxx-xxx.ngrok-free.app
```

**MCP URL**: `https://xxxx-xxx-xxx-xxx.ngrok-free.app/mcp` ← これをChatGPTに登録

## 📱 ChatGPTでの設定

1. ChatGPT設定 → **Connectors**
2. **Add Connector** をクリック
3. **MCP URL** に上記URLを入力
4. 保存

## 💡 使い方

ChatGPTで以下のように入力するだけ：

```
この動画を分析してください：
https://www.youtube.com/watch?v=VIDEO_ID
```

AIが自動的に：
1. シナリオ分析を実行 → 結果を共有
2. コメント分析を実行 → 結果を共有  
3. 感情分析を実行 → 最終結果を共有

## 📊 利用可能なツール

### 1. analyze-scenario（シナリオ分析）
- YouTube動画の文字起こしを取得
- 視聴者の感情を引き出す要素を9つの観点で分析

### 2. analyze-comments（コメント分析）
- コメントを最大1000件取得（カスタマイズ可能）
- いいね数順にソートして詳細分析

### 3. analyze-emotion（感情分析）
- シナリオとコメントの結果を統合
- 視聴者の心理的欲求を深く理解

## 🔧 トラブルシューティング

### サーバーが起動しない
```bash
# ポートを確認
lsof -ti:8004 | xargs kill -9

# 再起動
venv/bin/uvicorn main:app --host 0.0.0.0 --port 8004
```

### YouTube APIエラー
- APIキーが正しく設定されているか確認
- API使用制限（1日10,000クォータ）を超えていないか確認

### 文字起こしが取得できない
- 動画に字幕が有効になっているか確認
- 別の動画で試してみる
